# ReadXP

ReadXP is a mobile-first “BookTok” reading experience: swipe through memorable public-domain excerpts, react to them, and save books you want to continue.

## Run it

1. Install dependencies with `pnpm install`.
2. Start the Expo development server with `pnpm start`.
3. Open the project in Expo Go, an iOS Simulator, or an Android Emulator.

## Current prototype

- Full-screen vertical, paginated excerpt feed
- Four themed classic-book stories
- Like and save interactions with haptic feedback
- Reading progress and book metadata
- Discover, Library, and Profile product states
- Responsive safe-area layout for iOS, Android, and web

The sample excerpts are from public-domain works. Before a production release, verify public-domain status in every distribution territory and replace abbreviated engagement figures with real backend data.
